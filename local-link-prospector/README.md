# Prospector de enlaces y citaciones locales (SEO + GEO)

Herramienta complementaria del ecosistema. A partir de la ficha de **Google
Business Profile** o de la web de un negocio local, entrega un **mapa priorizado
de oportunidades gratuitas** donde dar de alta el negocio: directorios
generalistas y sectoriales, citaciones NAP y backlinks no-directorio
(asociaciones, prensa local, patrocinios, listicles, gremios). Cubre **España y
LATAM**. Idioma de salida: **español de España**.

## Cómo se invoca

- «local-link-prospector»
- «dónde doy de alta este negocio» / «directorios para esta ficha»
- «links gratuitos para SEO local» / «citations para Google My Business»

## Qué necesita

- **Obligatorio (uno de los dos):** URL de la ficha de Google Business Profile
  o URL de la web local.
- **Opcional (mejora mucho el resultado):** NAP canónico (nombre, dirección y
  teléfono), sector, zona, competidores locales para el gap y altas ya hechas.

## Cómo trabaja

1. **Fase 0. Briefing:** recoge los inputs.
2. **Fase 1. Análisis:** fija el NAP canónico, el sector, el país y la zona, y
   confirma contigo el perfil.
3. **Fase 2. Prospección por capas:** universal → generalistas ES/LATAM →
   **sectoriales (máxima prioridad)** → oportunidades creativas, ampliando con
   búsqueda en vivo y con el gap frente a la competencia.
4. **Fase 3. Puntuación:** relevancia, autoridad, tráfico real, tipo de enlace,
   esfuerzo y valor GEO, más prioridad 🔴/🟠/🟡, destino (ficha o web) y fase.
5. **Fase 4. Verificación en vivo:** comprueba que el sitio existe, que el alta
   es gratuita y que corresponde al país, y localiza la URL exacta de alta.
6. **Fase 5. Monitorización:** consistencia NAP, nuevas citaciones de la
   competencia y estado de cada alta.

## Qué entrega

Un análisis del negocio (sector, zona y NAP), el gap frente a la competencia y
un **Excel checklist con branding Growth Origin** que recoge cada oportunidad: tipo (citation o backlink),
destino, prioridad, URL de alta, fase de ejecución (semana 1 → mes 1 → …) y una
columna de estado para el seguimiento.

## Requisitos

Ninguno de pago. Usa búsqueda web para ampliar y verificar.
